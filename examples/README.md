# Online Boutique Microservices

This project is an enhanced version of the Apache Dubbo `online_boutique_demo`. It can be run locally; if you need to modify the source code, please test it locally before submitting changes to this project.

## Local execution

Execute the startup script：

```bash
./scripts/build-services.sh
```

Accessible after startup is complete：http://127.0.0.1:8080

Execute the cleanup script：

```bash
./scripts/stop-services.sh
```
